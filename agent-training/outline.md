# 高级推理框架与多 Agent 协作 · 培训大纲

120 分钟 · Java 后端 / 前端 / 客户端开发者 · 远程诊断业务仿真

学习目标：按任务复杂度选择推理与协作方式；设计包含角色、工具、消息、状态和结束条件的简单系统。

## 开场与目标｜5 分钟

- 01. 高级推理框架与多 Agent 协作（1 分钟）
- 02. 120 分钟：从判断题走到可运行系统（2 分钟）
- 03. 道通远程专家：接单前资料初审与专家辅助（2 分钟）

## Agent 基础｜13 分钟

- 04. 认识 Agent 的组成部分（4 分钟）
- 05. 本课学习路线：会判断、懂协作、能搭建（3 分钟）
- 06. 普通程序、工作流和智能体有什么不同？（6 分钟）

## 能力演进｜13 分钟

- 07. 能力演进 ①：大语言模型 LLM（1 分钟）
- 08. 能力演进 ②：检索增强生成 RAG（2 分钟）
- 09. 能力演进 ③：工具调用 Tool Calling（2 分钟）
- 10. 能力演进 ④：推理与行动交替 ReAct（2 分钟）
- 11. 能力演进 ⑤：规划执行 Plan-and-Execute（2 分钟）
- 12. 能力演进 ⑥：反思修订 Reflexion（2 分钟）
- 13. 能力演进 ⑦：多智能体 Multi-Agent（2 分钟）

## 按复杂度选择方案｜12 分钟

- 14. 决策卡：选择能解决问题的最简单方案（3 分钟）
- 15. 互动 ①：固定字段检查，需要 Agent 吗？（3 分钟）
- 16. 互动 ②：每次缺失的证据不同，如何处理？（3 分钟）
- 17. 互动 ③：何时值得拆成多个角色？（3 分钟）

## 多 Agent 协作设计｜22 分钟

- 18. 先定义角色产物，再讨论角色数量（3 分钟）
- 19. 模式 ①：主管 Supervisor，集中分派与汇总（3 分钟）
- 20. 模式 ②：并行 Parallel，先判断是否独立（3 分钟）
- 21. 模式 ③：评审 Review，用明确标准修订（3 分钟）
- 22. 消息 Message：接收方不应该猜上下文（3 分钟）
- 23. 共享状态 State：事实、草稿与批准分开（4 分钟）
- 24. 协作结束：谁有权说“够了”？（3 分钟）

## 三种框架的工程取舍｜12 分钟

- 25. 本课为什么选 LangGraph：约束先于框架（1 分钟）
- 26. 约束改变时：何时考虑另外两种框架（2 分钟）
- 27. 比较 ②：恢复、生态与维护成本（3 分钟）
- 28. 维护现状：选型前必须核对的事实（2 分钟）
- 29. AutoGen 与 MetaGPT：结构映射即可入门（2 分钟）
- 30. LangGraph：把协作设计变成显式图（2 分钟）

## 工作流基线与三个短演示｜15 分钟

- 31. 固定工作流 Workflow：完成原始任务（2 分钟）
- 32. 短演示 ①：主管委派 Supervisor / 重新分派（4 分钟）
- 33. 短演示 ②：并行分析 Parallel / 证据冲突（3 分钟）
- 34. 短演示 ③：评审修订 Review / 缺失电压（4 分钟）
- 35. 基线与三种模式：新增复杂度换来了什么（2 分钟）

## 综合实战与落地｜28 分钟

- 36. 综合设计：四角色、一份状态、一个出口（3 分钟）
- 37. LangGraph API 骨架：独立教学示例（3 分钟）
- 38. 扩展设计：未来如何替换为 LLM 决策（2 分钟）
- 39. HTTP 集成：Java、前端与客户端如何接入（3 分钟）
- 40. 综合运行台：看清证据、反馈与停止（7 分钟）
- 41. 小组练习：等待客户端上传，再恢复任务（5 分钟）
- 42. 交付检查清单：能解释，也能验证（2 分钟）
- 43. 参考资料：推理与协作模式（1 分钟）
- 44. 参考资料：框架与道通远程专家（2 分钟）
