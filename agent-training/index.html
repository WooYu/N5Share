概念 ⑥：Reflexion 把失败反馈变成改进动作

在规划执行之后记录“哪里错、下一次怎么改”，再把这份反思带入新的尝试。

反思记录是“下次执行的提醒”，会进入后续上下文，不会直接改变模型权重。

与规划执行组合：计划 → 执行 → 反馈 → 反思 → 修订 → 再验收。

概念 ⑦：多 Agent 按职责协作

不同角色各自处理任务，再通过消息交付结果；共享状态保存大家共同认可的进度与证据。

消息：谁交给谁、交付结果、证据来源共享状态：预算、已有证据、计划版本、完成情况

天气角色排除户外，费用角色核算总价，汇总角色找到同时满足两项条件的方案。

多个角色可以共用同一个模型；分工要有收益，协作要有明确出口。

第七步：设计共享状态

状态域主要写入者更新规则
observations工具与角色适配器追加证据、来源和工具错误

事实、建议、审查和人工批准使用不同字段与写入权限。

第八步：处理冲突、重试与版本

情况处理规则禁止做法
同一证据重复返回按引用或幂等键去重每次重试都追加一份
