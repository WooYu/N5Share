## 七个互动演示

P09 ReAct、P16 Plan-and-Execute、P25 Supervisor、P27 层次化、P29 Swarm、P40 双 Agent、P48 代码检视使用同一个播放器。可逐步执行、自动播放、点击事件回看、查看结构化事件与共享状态写入者。切换天气或预算会重置剧本。

离线界面固定标识“**预设教学剧本**”：轨迹人工编写，不能当作模型能力证据。`thought` 只展示简短决策摘要，不代表或披露模型内部思维。

默认雨天 / 300 元：先选植物园的计划 v1 在天气可行性检查失败，执行方回传观察，规划方加入天气前置与类型过滤，计划 v2 选择科技馆。完整费用：植物园 270、科技馆 210、美术馆 200、城市公园 120 元，均包括 80 元餐费。雨天 / 200 元可选美术馆；100 元应请求调整约束，不能输出验收通过。晴天不制造虚假的雨天失败。

代码检视包含四角色并行审查、汇总、审计与延迟的真实冲突、未经测量的对象开销顾虑、综合方案、修订与复审。数据、权限配置和测试结果均为课程合成资料；未修改或测试真实 Java 项目。代码改进建议仍需真实项目验证。

## 可选：DeepSeek 真实运行

需要 Python 3.11+ 和网络。Windows 在本目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r server/requirements.txt
.\.venv\Scripts\python.exe server/app.py --port 8775
```

或安装依赖后双击 `start-demo.cmd`：它会启动本机服务并自动打开 **http://127.0.0.1:8775**，已有服务会直接复用。服务在后台运行；不要使用普通静态服务器或 file:// 访问真实接口。离线课件的顶部和演示区提供“服务版”入口，并保留当前页码。

“真实运行”按钮置灰时，演示区会持续显示原因，不会被单步演示覆盖。Windows 首次配置请双击 `configure-deepseek.cmd`，在本机终端中隐藏输入 API Key；保存后返回服务版点击“重新检测”，无需重启服务。密钥无需发送到聊天或输入浏览器。

密钥读取顺序为环境变量 `DEEPSEEK_API_KEY`，其次 Windows 用户目录 `%LOCALAPPDATA%\N5AI\deepseek.key.dpapi`。与现有课件共用存放位置，但不依赖其代码。密钥不发给浏览器、不写入包。其它操作系统使用环境变量。

首次配置可以重新检测后启用；已经在使用中的密钥若需更换，请重启服务，以免替换正在运行的模型会话。

服务调用 DeepSeek 官方接口 `https://api.deepseek.com/chat/completions`，模型 `deepseek-flash`，JSON 对象输出、关闭 thinking。模型决定结构化动作；本地宿主执行白名单工具、回填观察、合并状态和验收。真实模型可能选出不同路径，也可能失败；超限或异常会明确显示，**不会切回剧本冒充真实模型**。

每次运行上限为 12 次模型调用、20 次工具调用、480 秒，可取消。计数与 token 用量显示在演示栏；调用按供应商规则计费。服务仅监听 127.0.0.1，只提供明确列出的课件文件和 API，拒绝跨源请求。所有工具仍读取课程合成数据，不查询真实天气、不订票、不连接业务系统。当前版本不实现生产持久化、审批系统或恢复。

API：`GET /api/health`、`POST /api/runs`、`GET /api/runs/{run_id}`、`POST /api/runs/{run_id}/cancel`。运行请求例：`{"scenario":"dual","weather":"rain","budget":300}`。接口均为同源 JSON。

## 修改内容与验证

- `slides/`：一章一个普通 JS 文件，修改投影内容、时长、讲稿、判断题与演示引用。
- `assets/`：配色、固定舞台、导航、共享演示播放器。`content-kit.js` 提供内容排版与 SVG 小函数。
- `data/`：场馆资料、事件快照、双 Agent 与代码检视剧本。
- `server/`：可选模型服务；不参与离线播放。
- `notes/`：大纲和逐页讲稿。修改章节后运行 `node tools/export-notes.cjs` 可同步导出；播放课件无需此步骤。

```powershell
node --test tests/scenarios.test.cjs
```

后端测试（使用 mock 模型，不产生模型用量）：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py" -v
```
